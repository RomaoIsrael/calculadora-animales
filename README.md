# ¿Es buen negocio? 🐄

Calculadora para celular que dice, en palabras simples, si comprar animales de granja en Ecuador es buen negocio.

**Abrir la app:** https://romaoisrael.github.io/calculadora-animales/

- Un solo archivo `index.html` (HTML + CSS + JS), gráficos con Chart.js desde jsDelivr.
- Funciona sin conexión después de la primera visita (`sw.js`) y se puede instalar en la pantalla de inicio (`manifest.json`).
- Los datos que escribes y la lista "Antes de comprar" se guardan en tu teléfono (localStorage).

Valores de referencia investigados en septiembre de 2026 para Ecuador. Herramienta de análisis, no asesoría financiera.
